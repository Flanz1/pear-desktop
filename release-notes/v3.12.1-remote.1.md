First release of the **Pear Desktop Remote** desktop app and the **Pear Remote** Android app.

## What's new
- **Phone remote.** Control playback from your phone over your home network: play/pause, skip, seek, volume and mute, shuffle and repeat, and the queue.
- **Browse and search on the phone.** Home shelves, your library (playlists, albums, artists, songs, liked) and search, then start playback from the phone. All requests go through the desktop; the phone never contacts Google.
- **Secure pairing.** The phone remote is off until you enable it in the desktop app. Pair with a QR code or 6-digit code and confirm on the desktop. Each phone gets its own revocable token, and you can see and remove paired phones in the desktop app.
- Based on upstream Pear Desktop 3.12.1.

## Install
- **Desktop (Windows):** `Pear-Desktop-Remote-Setup-*.exe` (installer) or `Pear-Desktop-Remote-Portable-*.exe`. It installs next to Pear Desktop, with its own settings, and does not replace it. The app is not code-signed, so Windows SmartScreen will warn on first run (More info, then Run anyway).
- **Desktop (Linux):** `.AppImage`, `.rpm` or `.deb` (x64).
- **Phone (Android 8.0+):** `Pear-Remote-*.apk`. No Google services are used.
- Verify downloads with `SHA256SUMS.txt`.

## Compatibility
- Protocol 1.1 on both sides. A phone app that speaks 1.0 still works with this desktop; it just doesn't get browse and search.
- **Update your phone app** to this release for browse and search.

## Updates and rollback
The desktop app checks this repository's releases for updates and asks before downloading. To roll back, install the previous release; the older Android APK can be installed over this one only if its version code is not lower, so uninstall first when downgrading.

## Known limits
- macOS is not built.
- No Windows code signing.
