Second release of this fork: Pear Desktop with the phone remote built in, plus the **Pear Remote** Android app.

## What's new since remote.1
- **Phone app keeps its connection in the background.** The Android app now stays connected to your desktop while the screen is off or the app is in the background, with a pinned media notification for playback controls.

## What's included
- **Phone remote.** Control playback from your phone over your home network: play/pause, skip, seek, volume and mute, shuffle and repeat, and the queue.
- **Browse and search on the phone.** Home shelves, your library and search, then start playback from the phone. All requests go through the desktop; the phone never contacts Google.
- **Secure pairing.** The phone remote is off until you enable it in the desktop app. Pair with a QR code or 6-digit code and confirm on the desktop. Each phone gets its own revocable token.
- Based on upstream Pear Desktop 3.12.1.

## Install
- **Desktop (Windows):** `Pear-Desktop-Remote-Setup-*.exe` (installer) or `Pear-Desktop-Remote-Portable-*.exe`. It installs over an existing Pear Desktop / YouTube Music install (same app ID) and keeps your settings. The app is not code-signed, so Windows SmartScreen will warn on first run (More info, then Run anyway).
- **Desktop (Linux):** `.AppImage`, `.rpm` or `.deb` (x64).
- **Phone (Android 8.0+):** `Pear-Remote-*.apk`, installs over the previous version. No Google services are used.
- Verify downloads with `SHA256SUMS.txt`.

## Compatibility
Protocol 1.1 on both sides, unchanged from remote.1. Update the phone app for the background-connection fix.

## Known limits
- macOS is not built.
- No Windows code signing.
